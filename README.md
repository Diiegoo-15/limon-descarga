# Limón 🍋🐱

Limón, paseando por tu Mac para hacerte compañía. 🧡

## Instalarlo (30 segundos)

1. Pulsa **⌘ + espacio**, escribe **Terminal** y pulsa **Intro**.
2. Pega esta línea (**⌘ + V**) y pulsa **Intro**:

```
curl -fsSL https://raw.githubusercontent.com/Diiegoo-15/limon-descarga/main/instalar.sh | bash
```

3. ¡Listo! Limón aparecerá en tu pantalla y se abrirá solo cada vez que enciendas el Mac.

Para actualizarlo, haz lo mismo otra vez.

## Cómo jugar con él

- Pasa el ratón por encima: ronronea 💕
- Haz clic: maúlla y se pone panza arriba
- Arrástralo: lo coges en brazos
- En la barra de arriba, su cabecita tiene un menú: tamaño, sonido, **Dar chuche 🐟**…

Requiere macOS 13 o superior.
